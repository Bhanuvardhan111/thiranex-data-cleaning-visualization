# Data Cleaning & Visualization Project

## Objective
The objective of this project is to clean, process and visualize
a raw dataset to identify useful insights.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Data Cleaning
- Missing values handled
- Duplicate records removed
- Outliers detected and handled
- Statistical analysis performed

## Data Visualization
- Histograms
- Boxplots
- Bar charts
- Correlation heatmap
- Pair plots

## Outcome
The project demonstrates data preprocessing, cleaning,
visualization and extraction of meaningful insights from data.
